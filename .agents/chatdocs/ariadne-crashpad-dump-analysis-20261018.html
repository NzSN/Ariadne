Why the controlled fixture constructs zero

This separate reference calculation uses the known routine and captured values. It is distinct from Ariadne’s zero-address assessment and its dependency explanation.

Captured inputs:         [3, 5, 8, 13, 21, 34, 55, 89]
Captured [RSP + 0x10]:   0x4be91
Add 17:                 0x4bea2
Captured R11:           0x4bea2
Encoded difference:     R11 − ([RSP + 0x10] + 17) = 0  (mod 2^64)
Captured R8 / RAX / RCX: 0 / 0 / 0

The native routine deliberately subtracts its computed checksum from the expected checksum before the store. The reference values agree with the captured zero registers. This calculation supplies no general historical memory contents, branch trace or stronger value-origin conclusion.
