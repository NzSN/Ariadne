1. Source checking is one link in the completion chain

The new source pack describes the GF2 inverse-affine equation and operand rules, MOVD transfer/prefix statements, and scalar FMA operand/rounding statements. It deliberately preserves contradictory manual text. There is no new numeric GF inversion, IEEE FMA implementation, production opcode correction, vector must-def, or runtime admission in this continuation.

For example, knowing that the manual writes a particular upper-clear range does not justify using that range to kill old value origins when the same statement includes a bit outside the register. Such a write needs an adjudicated source contract and an implemented, validated projection rule.
