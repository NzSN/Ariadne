2. Complete I5c full qualification

W5 must show that the integrated feature preserves its conclusions, uncertainty and existing behavior under the exact qualified source/tool/dependency snapshot.

  1. Run the required checks. Exercise affected Rust tests, root format/test/Clippy/layout/documentation checks, explicitly ignored native cases, the question model, analysis/native replay and relevant Stage E/input/BAP/investigation regressions. Use a sealed MirrorRust dependency snapshot and separate replay/mutation build directories.
  2. Demonstrate mutation sensitivity. Deliberately introduce wrong signedness, wrong wrap boundaries, missing receipt/context/range checks, incorrect unknown handling and seed-to-root mistakes. Observers must reject actual compiled behavioral defects; compile failures and timeouts earn no mutation credit.
  3. Refresh compatibility evidence. Preserve the legacy base/explanation/I5a/I5b outputs and their original identities. Requalify affected I5a/I5b finite and controlled tiers; recheck the independent I4 Windows 2,000 ms CLI and Linux 250 ms phase criteria on their exact pins.
  4. Meet the frozen I5c budgets. Measure binding + assessment + all-format rendering separately from the normal release CLI, using one warm-up and five measured runs. The ceilings are 10 ms phase median and 1,500 ms CLI median. Measure the eight owned controlled cases separately.
  5. Seal durable evidence. Retain source snapshots, raw logs/samples/reports, capture inspections, mutant outcomes and rejected attempts. Verify every archive member's size/hash. Publish distinct source/fixture, controlled-partial, controlled-full and full-I5c acceptance results, then update canonical status documents to the demonstrated scope.
