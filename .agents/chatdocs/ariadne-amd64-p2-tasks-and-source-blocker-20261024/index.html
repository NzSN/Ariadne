The exact source inconsistency

Input bytePublished lookupField inversionProduct with published value
F05B5B01
F15B235A

Two distinct nonzero elements cannot share the same multiplicative inverse. The adjacent GF2P8MULB definition supplies polynomial 011B. Under that field, F1 × 5B = 5A, rather than 01. Inversion by exhaustive search and independent exponentiation both give 23. The remaining 255 published lookup entries agree with the comparison, including the specified zero-to-zero convention.

  • Official Vol4 revision 3.27, PDF page 228: row F_, column _1 contains 5B. Source cell pdf:228:cell:67, word 0.
  • The predecessor Vol4 table, PDF page 226, also contains 5B, at pdf:226:cell:292, word 0.
  • Official combined revision 4.10, PDF page 2229 repeats the same table.

Fresh publisher downloads of Vol3, Vol4 and the combined manual returned HTTP 200 and matched their pins. The publisher index identifies the selected Vol4 and combined editions as latest in its returned metadata. Both relevant table pages were visually inspected after rendering; the duplicate values are present in the page images.

Queries covered publication IDs, AMD64 errata, NullSelectorClearsBase, GF2P8AFFINEINVQB and VCVTPH2PS. No correcting publisher answer was found in those results. This is a bounded search, not a claim that no erratum exists anywhere.

The mathematical comparison is a counterexample to the claimed inverse property. It does not establish AMD's intended correction or real hardware behavior.
